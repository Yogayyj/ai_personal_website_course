第6课：HTML 标签入门

本课带学生认识常用 HTML 标签，掌握最基础的网页格式，并学会在个人网站中加入图片、音乐和链接。

课堂目标：学生能读懂一份简单 HTML 文件，并能独立修改文字、插入图片、播放音乐、添加跳转链接。

一、HTML 标签是什么？

HTML 由一个个“标签”组成。标签告诉浏览器：这里是一段标题、这里是一张图片、这里是一个链接、这里可以播放音乐。

<标签名>内容</标签名>

大多数标签有开始标签和结束标签，例如 <p> 与 </p>。也有一些标签不需要结束标签，例如图片标签 <img>。

二、最简单的 HTML 文件格式

一个网页通常从下面这个基本结构开始：

<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>我的个人网站</title>
</head>
<body>
  <h1>你好，我是 Alex</h1>
  <p>欢迎来到我的个人网站。</p>
</body>
</html>
  • <head>：放网页设置，例如标题、编码、搜索描述。
  • <body>：放真正显示在页面上的内容。
  • <title>：显示在浏览器标签页上的标题。

三、常用 HTML 标签速查表

标签作用示例
<h1> 到 <h6>标题，数字越小越重要。<h1>我的作品集</h1>
<p>段落文字。<p>我喜欢机器人和设计。</p>
<br>换行。第一行<br>第二行
<strong>重要文字，通常显示为加粗。<strong>重点项目</strong>
<em>强调文字，通常显示为斜体。<em>Creative Coding</em>
<ul> / <ol> / <li>无序列表、有序列表和列表项。<li>项目一</li>
<div>通用容器，用来分组内容。<div>关于我区域</div>
<span>行内小容器，常用于给一小段文字加样式。<span>关键词</span>
<img>插入图片。<img src="avatar.jpg" alt="我的头像">
<a>添加链接。<a href="https://github.com">GitHub</a>
<audio>插入音乐或音频。<audio src="music.mp3" controls></audio>

四、文字内容：标题、段落和列表

个人网站最常见的内容是“我是谁”“我做过什么”“我的项目有哪些”。可以用标题、段落和列表组织信息。

<h1>Alex Chen</h1>
<p>我是一名对计算机科学、AI 和交互设计感兴趣的学生。</p>

<h2>我的兴趣方向</h2>
<ul>
  <li>人工智能应用</li>
  <li>网页设计</li>
  <li>机器人项目</li>
</ul>

五、怎么加图片？

插入图片使用 <img> 标签。最重要的两个属性是 src 和 alt。

  • src：图片文件的位置。
  • alt：图片无法显示时的替代文字，也能帮助搜索引擎和屏幕阅读器理解图片。
<img src="avatar.jpg" alt="Alex 的个人头像" width="240">

如果图片放在 images 文件夹里，路径要写成：

<img src="images/avatar.jpg" alt="Alex 的个人头像" width="240">
注意：文件名大小写要完全一致。Avatar.JPG 和 avatar.jpg 在网站上线后可能会被识别为两个不同文件。

六、怎么加音乐？

插入音乐使用 <audio> 标签。课堂项目建议一定加上 controls，这样访客可以自己播放、暂停和调节进度。

<audio src="music.mp3" controls></audio>

如果音乐文件放在 assets 文件夹里，可以这样写：

<audio controls>
  <source src="assets/background-music.mp3" type="audio/mpeg">
  你的浏览器不支持音频播放。
</audio>
  • 常见音频格式：.mp3、.wav、.ogg。
  • 不要自动播放背景音乐；让访客自己点击播放更礼貌，也更符合浏览器规则。
  • 使用音乐前要注意版权，优先使用自己创作或可免费授权的音乐。

七、怎么加链接？

链接使用 <a> 标签。href 表示点击后要打开的地址。

<a href="https://github.com/your-username">访问我的 GitHub</a>

如果想让链接在新标签页打开，可以加 target="_blank" 和 rel="noopener noreferrer"：

<a href="https://github.com/your-username" target="_blank" rel="noopener noreferrer">
  访问我的 GitHub
</a>

链接也可以跳转到同一个网站里的其他页面：

<a href="about.html">关于我</a>
<a href="projects.html">我的项目</a>

八、路径怎么理解？

网页引用图片、音乐或其他页面时，最容易错的是“路径”。路径就是告诉浏览器文件在哪里。

文件位置写法意思

在子文件夹 images 里images/avatar.jpg先进入 images 文件夹，再找图片。
回到上一层文件夹../index.html../ 表示上一层。

九、完整小练习：做一个个人介绍卡片

把下面代码复制到 index.html，再把姓名、介绍、图片、音乐和链接换成自己的内容。

<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>我的个人介绍</title>
</head>
<body>
  <h1>Alex Chen</h1>
  <p>我喜欢 AI、网页设计和机器人项目。</p>

  <h2>我的照片</h2>
  <img src="images/avatar.jpg" alt="Alex 的个人头像" width="240">

  <h2>我喜欢的一段音乐</h2>
  <audio src="assets/music.mp3" controls></audio>

  <h2>我的链接</h2>
  <a href="https://github.com/your-username" target="_blank" rel="noopener noreferrer">
    我的 GitHub
  </a>
</body>
</html>

作业

请完成一个包含标题、段落、列表、图片、音乐和至少一个外部链接的 index.html 页面。

  • 图片可以使用个人头像、项目截图或作品照片。
  • 音乐请使用自己拥有使用权的音频文件。
  • 链接可以指向 GitHub、作品集、学校项目或你想展示的网页。

提交前检查：文件名是否正确、路径是否正确、图片和音乐是否能正常加载。
