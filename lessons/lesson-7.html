第7课：网页界面的美学设计

本课帮助学生理解网页不是“把内容放上去”就结束，而是要通过颜色、字体、间距、布局和视觉层级，让访客快速理解信息并产生专业印象。

课堂目标：学生能说出网页美学设计的基本原则，并能用 CSS 调整颜色、字体、留白、卡片和按钮，让个人网站更清晰、更统一、更适合大学申请展示。

一、什么是网页界面的美学设计？

网页界面的美学设计（UI Aesthetic Design）不是单纯“做得好看”，而是让页面同时具备：

  • 清晰：访客一眼知道你是谁、你想展示什么。
  • 统一：颜色、字体、按钮、卡片风格保持一致。
  • 重点明确：重要信息更醒目，次要信息不抢戏。
  • 可信专业：适合申请、作品集和个人品牌展示。

二、网页美学的 6 个核心原则

原则含义个人网站中的做法
对齐 Alignment元素边缘有秩序，页面更稳定。标题、段落、卡片左边缘保持同一条线。
对比 Contrast重要内容和普通内容要有明显差异。主标题更大更粗，按钮使用强调色。
重复 Repetition重复使用同一种视觉样式形成统一感。所有项目卡片使用相同圆角、阴影和间距。
亲密性 Proximity相关内容放近，不相关内容拉开。项目标题、描述、链接放在同一张卡片里。
留白 White Space空白不是浪费，而是让内容更容易阅读。段落之间、模块之间留出足够距离。
层级 Hierarchy通过大小、颜色、位置引导阅读顺序。先看姓名和定位，再看项目，再看联系方式。

三、颜色：少即是多

初学者最常见的问题是颜色太多。个人网站建议使用一个简单配色系统：

  • 背景色：页面底色，例如浅灰、米白、深色。
  • 文字色：正文要清楚易读，避免太浅。
  • 强调色：用于按钮、链接、重要标签。
  • 边框/辅助色：用于卡片分隔和弱化信息。
背景 #F7F7F5
卡片 #FFFFFF
文字 #111111
辅助 #666666
强调 #2F66FF
:root {
  --bg: #f7f7f5;
  --card: #ffffff;
  --text: #111111;
  --muted: #666666;
  --accent: #2f66ff;
}
课堂建议：一个页面通常控制在 1 个强调色 + 2 到 3 个中性色以内。颜色越少，越容易显得高级和专业。

四、字体：先保证可读性

字体设计的核心不是“花”，而是“读起来舒服”。个人网站建议使用系统字体，加载快、兼容好、看起来干净。

body {
  font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Microsoft YaHei", Arial, sans-serif;
  line-height: 1.7;
}
  • 正文不要太小，建议 16px 到 18px。
  • 标题可以更大、更粗，用来建立视觉层级。
  • 同一页面不要混用太多字体，通常 1 到 2 种就够。

五、间距和留白：让页面会呼吸

优秀页面往往不是内容更多，而是信息之间的距离更合理。可以用 padding、margin 和 gap 控制留白。

.section {
  padding: 72px 0;
}

.card {
  padding: 28px;
  margin-bottom: 18px;
}

.project-grid {
  display: grid;
  gap: 20px;
}

判断间距是否合适的简单方法：眯起眼睛看页面，如果所有内容挤成一团，就需要增加留白；如果页面太空、信息断开，就需要减少间距。

六、布局：先做清楚，再做复杂

个人网站最推荐的布局是“顶部介绍 + 内容模块 + 卡片网格”。它容易阅读，也适合展示项目、经历和作品。

<section class="hero">
  <h1>Alex Chen</h1>
  <p>AI / Design / Robotics Student</p>
</section>

<section class="projects">
  <div class="project-card">项目一</div>
  <div class="project-card">项目二</div>
</section>
.projects {
  display: grid;
  grid-template-columns: repeat(2, 1fr);
  gap: 20px;
}

.project-card {
  background: white;
  border: 1px solid #e6e6e0;
  border-radius: 20px;
  padding: 24px;
}

七、图片和视觉素材：统一风格

图片会强烈影响网页气质。项目截图、头像、作品照片最好保持统一尺寸和圆角。

img {
  max-width: 100%;
  border-radius: 18px;
  display: block;
}

.avatar {
  width: 160px;
  height: 160px;
  object-fit: cover;
  border-radius: 50%;
}
  • 头像适合使用正方形图片，再用 border-radius: 50% 做成圆形。
  • 项目截图建议统一比例，例如都使用横向截图。
  • 不要使用模糊、拉伸变形或风格不统一的图片。

八、按钮和链接：让行动更明确

按钮通常用于最重要的行动，例如“查看项目”“下载简历”“联系我”。链接可以用于次要跳转。

.btn {
  display: inline-block;
  background: #111;
  color: white;
  text-decoration: none;
  padding: 12px 18px;
  border-radius: 999px;
  font-weight: 700;
}

.btn:hover {
  opacity: 0.88;
}

一个页面不要放太多同等重要的按钮，否则访客不知道先点哪个。

九、移动端美学：手机上也要好看

很多访客会用手机打开个人网站，所以页面必须适配小屏幕。最常见做法是使用媒体查询。

@media (max-width: 720px) {
  .projects {
    grid-template-columns: 1fr;
  }

  h1 {
    font-size: 42px;
  }
}

检查移动端时重点看：文字是否太小、按钮是否容易点击、卡片是否超出屏幕、图片是否变形。

十、AI 辅助美学优化 Prompt

你可以让 AI 帮你优化页面视觉，但要描述清楚目标和限制。

请帮我优化这个个人网站的界面美学。
目标：简洁、专业、适合大学申请作品集。
要求：
1. 使用统一配色，最多 1 个强调色。
2. 增加留白和视觉层级。
3. 优化项目卡片、按钮和移动端布局。
4. 不要改变原来的文字内容。
5. 输出完整 HTML/CSS 代码，并解释改动原因。

十一、课堂小练习：美化个人网站首页

  1. 选择 1 个强调色，并写成 CSS 变量。
  2. 给页面设置统一字体和正文行高。
  3. 给“项目”区域做成卡片样式。
  4. 为按钮添加圆角、内边距和 hover 效果。
  5. 添加一个移动端媒体查询，让卡片在手机上变成单列。

十二、设计检查清单

检查项问题
颜色是否控制在少量颜色内？强调色是否只用于重点？
字体正文是否容易阅读？标题是否足够醒目？
间距模块之间是否有足够留白？内容是否拥挤？
对齐标题、段落、卡片边缘是否整齐？
图片图片是否清晰、比例统一、不变形？
移动端手机上是否能正常阅读和点击？

作业

请对自己的个人网站首页做一次美学优化，并在提交说明中写出你修改了哪些设计点。

  • 至少修改颜色、字体、间距、卡片或按钮中的 3 项。
  • 保留优化前后的截图，方便课堂对比。
  • 用 3 到 5 句话说明：你的设计想给访客什么感觉？

提交前检查：页面是否统一、重点是否清楚、手机上是否好看。
